Mobile Operator, dev channel

The dev channel: the build of every merged brief, for Filippo alone. Not tested, not a release. The app people download is at tryhardfifi.github.io.

No build is offered by default. Several chats publish here minutes apart, so “the latest” belongs to whoever pushed last and is somebody else's build. Every build below installs itself, and a link you were sent stays that build after anybody else publishes.

iOS will not install a build older than the one already on this iPhone: taking a newer one means the older builds only install after deleting the app.
